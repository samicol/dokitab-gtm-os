# DokiTab GTM Context OS

The go-to-market context operating system for DokiTab (dokitab.com), an offline-first healthcare operating system and EMR platform for hospitals, clinics, diagnostic labs, and pharmacies in Nigeria and across Africa.

This repo holds the shared context, research, playbooks, and deliverables used to run DokiTab's go-to-market work. See [CLAUDE.md](CLAUDE.md) for how the folders are organised and the rules for working here.
